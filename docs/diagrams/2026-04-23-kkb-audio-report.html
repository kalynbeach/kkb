02

Ownership lanes

The current architecture works because the browser-specific objects do not leak into the shared package contract.

@kkb/audio

Headless runtime

Private workspace package with wildcard leaf exports only. It is consumed as TypeScript source and currently ships no compiled artifact.

  • contracts define track, timeline, source capability shapes.
  • engine owns source selection, recovery, store updates, and checkpoint preferences.
  • oscilloscope owns signal-provider contracts, XY geometry, WebGPU rendering, support checks, config and presets.
apps/web

Browser host

The Next.js app creates and tears down browser-only objects, then adapts them into package-level contracts.

  • create-web-player.ts creates Audio() elements and wires sources to AudioEngine.
  • create-mic-provider.ts owns getUserMedia, AudioContext, analysers, fake mic modes, and cleanup.
  • React clients own route lifecycle, hash persistence, support state, keyboard shortcuts, and controls.
@kkb/ui

Presentation layer

Shared audio UI components stay visual and controllable, while runtime truth comes from the host-provided player snapshot.

  • PlayerControls, Playhead, Waveform, and theme class names compose the player shell.
  • createPlayerPresenter derives labels, disabled states, progress and buffered segments.
  • The waveform remains decorative/static bars, with a live playhead overlay.

04

Oscilloscope runtime

The oscilloscope is the freshest and strongest area: browser capture stays in apps/web, while provider consumption, XY frame generation, and WebGPU passes stay inside @kkb/audio.

Rendering loop

SignalProvider → XY geometry → WebGPU canvas

  • OscilloscopeClient checks support, lazy-loads createOscilloscope, and stores config in the URL hash.
  • createMicProvider turns live or fake mic input into an analyser-backed SignalProvider.
  • createOscilloscope schedules frames, resizes for DPR, selects provider, and clamps trace points.
  • createWebGpuRenderer runs fade, trace, and composite passes against a history texture.
