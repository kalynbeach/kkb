Problem

OscilloscopeClient hides a session state machine inside React; 677 lines of DOM tests reach through presentation to verify races, teardown, support, and source switching.

Solution

Concentrate reusable startup, source switching, stale-request cancellation, failure, and disposal implementation in one app-local deep session module; keep URL/hash behavior in the React adapter.
