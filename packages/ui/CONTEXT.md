# UI

This context defines the shared interface language used by KKB applications.

## Language

**Seek timeline**:
An interactive playback-position control that presents elapsed, buffered, and remaining time without claiming to visualize audio amplitude.
_Avoid_: Waveform, scrubber

**Waveform**:
A visualization derived from analyzed audio amplitude data.
_Avoid_: Seek timeline, decorative waveform
